# 🌱 GreenLoop

### Smart Waste Management & Green Rewards

GreenLoop is a smart waste-management web application designed to help households record, monitor, and manage their waste while encouraging responsible waste segregation through a Green Coins reward system.

## 🚀 Features

- 🔐 User authentication
- 👨‍👩‍👧 Family/household management
- ♻️ Waste record management
- ⚖️ Total, dry, wet and recyclable waste tracking
- 🪙 Green Coins reward system
- 📊 Waste-management dashboard
- 📱 Responsive mobile-friendly interface
- 📲 Installable Progressive Web App (PWA)
- ✅ Waste-record validation
- 🗄️ PostgreSQL database
- ⚡ FastAPI backend
- ⚛️ React + TypeScript frontend

## 🏗️ Technology Stack

### Frontend
- React
- TypeScript
- Vite
- PWA support

### Backend
- Python
- FastAPI
- SQLAlchemy

### Database
- PostgreSQL
